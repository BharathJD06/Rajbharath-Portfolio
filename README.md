## 🌟 3D Video-Animated WebGL Portfolio

> 🚀 **Live Interactive Web App:** **[https://bharathjd06.github.io/Rajbharath-Portfolio/](https://bharathjd06.github.io/Rajbharath-Portfolio/)**

This repository hosts a state-of-the-art, **3D video-animated developer and data analytics portfolio** built with senior motion-designer aesthetics, hardware-accelerated 3D WebGL graphics, and comprehensive project telemetry.

### ✨ Key Interactive Features
- **🌐 Three.js 3D WebGL Nebula**: Interactive ambient starfield and wireframe cyber geometry reacting with physics inertia to mouse movement.
- **🎬 Senior Video Animator HUD**: Cinematic viewport brackets, live pulsing `REC [60 FPS]` recording indicator, real-time timecode ticker (`TC 00:00:00:00`), and location telemetry.
- **🔊 Synthesized Web Audio FX**: High-tech UI feedback sounds synthesized natively via the Web Audio API with a navigation equalizer mute toggle.
- **🎨 Dynamic Neon Theme Engine**: Real-time palette switcher (*Cyberpunk Cyan*, *Matrix Emerald*, *Synthwave Violet*, *Solar Gold*).
- **🔤 Global Poppins Typography**: Clean, contemporary aesthetic utilizing Google Font **Poppins** across all headings, cards, and UI components.
- **💻 Interactive Analyst Terminal**: Built-in interactive command console supporting quick macro queries (`skills`, `projects`, `experience`, `hire`, `contact`, `clear`).
- **🔍 23 Project Deep Dive Modals**: Glassmorphic modal overlays providing problem statements, execution methodologies, and verified impact metrics.
